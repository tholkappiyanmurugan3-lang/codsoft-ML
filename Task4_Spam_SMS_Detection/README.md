# Spam SMS Detection

## Project Overview

This project uses Machine Learning and Natural Language Processing (NLP) techniques to classify SMS messages as Spam or Ham (Legitimate).

## Dataset

The dataset contains SMS messages labeled as:

* Ham (Legitimate Message)
* Spam (Unwanted Message)

## Technologies Used

* Python
* Pandas
* NumPy
* Scikit-Learn
* TF-IDF Vectorization
* Google Colab

## Machine Learning Algorithm

* Multinomial Naive Bayes

## Project Workflow

1. Data Loading
2. Data Cleaning
3. Text Preprocessing
4. TF-IDF Vectorization
5. Train-Test Split
6. Model Training
7. Prediction
8. Model Evaluation

## Results

* Accuracy: 96.23%
* Successfully classified SMS messages as Spam or Ham.

## Evaluation Metrics

* Accuracy Score
* Precision
* Recall
* F1 Score
* Classification Report

## Features

* Spam Message Detection
* Natural Language Processing
* Text Vectorization
* Machine Learning Classification

## How to Run

1. Open the notebook in Google Colab.
2. Upload the spam dataset.
3. Run all cells.
4. Test custom SMS messages.
